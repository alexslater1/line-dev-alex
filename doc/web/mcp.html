MCP Integration

LINE exposes its queueing analysis capabilities as a Model Context Protocol (MCP) server, allowing Large Language Models (such as Claude) to build, solve, and analyze queueing models conversationally. Instead of writing code manually, you describe your system in natural language and the LLM calls LINE tools to produce quantitative results.

Setup

Installation

Install the LINE solver Python package:

pip install line-solver

Or clone the repository and install in development mode:

git clone https://github.com/imperial-qore/line-solver.git
cd line-solver/python
pip install -e .
pip install mcp numpy pandas

Claude Desktop Configuration

Add the following to your claude_desktop_config.json:

{
  "mcpServers": {
    "line-solver": {
      "command": "python",
      "args": [
        "/path/to/line-solver/python/mcp_server.py"
      ]
    }
  }
}

Claude Code Configuration

For Claude Code (CLI), add to your .claude/settings.json:

{
  "mcpServers": {
    "line-solver": {
      "command": "python",
      "args": [
        "/path/to/line-solver/python/mcp_server.py"
      ]
    }
  }
}

Replace /path/to/line-solver with the actual path to your LINE installation.

Quick-Start Examples

These tools require no code. Just provide parameter values and the LLM handles the rest.

Open Queue Analysis

Prompt: “Analyze an M/M/1 queue with arrival rate 2 and service rate 5.”

The LLM calls analyze_queue(arrival_rate=2.0, service_rate=5.0) and returns:

Closed Network Analysis

Prompt: “Analyze a closed system with 10 users, 5 seconds think time, and service rate 2.”

# The LLM calls:
analyze_closed_network(population=10, think_time=5.0, service_rate=2.0)

Parameter Sweep

Prompt: “How does queue length change as arrival rate goes from 0.5 to 4.5 in steps of 0.5, with service rate 5?”

# The LLM calls:
sweep_parameter(param="arrival_rate", values="0.5:4.5:0.5", service_rate=5.0)

Custom Models

The solve_line_model tool executes arbitrary LINE Python code in a sandboxed environment with from line_solver import *, numpy, and pandas pre-loaded.

Open Network

model = Network('M/M/1')
source = Source(model, 'Source')
queue = Queue(model, 'Queue', SchedStrategy.FCFS)
sink = Sink(model, 'Sink')

oclass = OpenClass(model, 'Class1')
source.setArrival(oclass, Exp(1.0))
queue.setService(oclass, Exp(2.0))

model.link(Network.serial_routing([source, queue, sink]))
avg_table = MVA(model).avg_table()
print(avg_table)

Closed Network

model = Network('ClosedQN')
delay = Delay(model, 'Think')
queue = Queue(model, 'Queue', SchedStrategy.PS)

cclass = ClosedClass(model, 'Users', 5, delay)
delay.setService(cclass, Exp(1.0))
queue.setService(cclass, Exp(3.0))

model.link(Network.serial_routing([delay, queue]))
avg_table = MVA(model).avg_table()
print(avg_table)

Multiclass Network

model = Network('Multiclass')
source = Source(model, 'Source')
queue = Queue(model, 'Queue', SchedStrategy.FCFS)
sink = Sink(model, 'Sink')

class1 = OpenClass(model, 'Web')
class2 = OpenClass(model, 'API')

source.setArrival(class1, Exp(1.0))
source.setArrival(class2, Exp(0.5))
queue.setService(class1, Exp(4.0))
queue.setService(class2, Exp(3.0))

model.link(Network.serial_routing([source, queue, sink]))
avg_table = MVA(model).avg_table()
print(avg_table)

Advanced Tools

Solver Comparison

Run the same model with multiple solvers and compare results:

# Using compare_solvers tool with solvers="MVA,NC,MAM"
model = Network('M/M/1')
source = Source(model, 'Source')
queue = Queue(model, 'Queue', SchedStrategy.FCFS)
sink = Sink(model, 'Sink')
oclass = OpenClass(model, 'Class1')
source.setArrival(oclass, Exp(1.0))
queue.setService(oclass, Exp(2.0))
model.link(Network.serial_routing([source, queue, sink]))

Model Visualization

Generate Mermaid diagrams showing network topology, node types, and class information:

# Using visualize_model tool
model = Network('WebApp')
source = Source(model, 'Arrivals')
lb = Queue(model, 'LoadBalancer', SchedStrategy.PS)
app = Queue(model, 'AppServer', SchedStrategy.FCFS)
sink = Sink(model, 'Departures')
oclass = OpenClass(model, 'Requests')
source.setArrival(oclass, Exp(5.0))
lb.setService(oclass, Exp(100.0))
app.setService(oclass, Exp(10.0))
P = model.initRoutingMatrix()
P[oclass, source, lb] = 1.0
P[oclass, lb, app] = 1.0
P[oclass, app, sink] = 1.0
model.link(P)

The output is a Mermaid diagram renderable by GitHub, Notion, Mermaid Live Editor, and other tools.

Example Gallery

Browse and retrieve LINE's built-in examples:

  • list_examples() — categorized list of all available examples
  • get_example_code("gallery_mm1") — retrieve source code for a specific example

Example categories include: open queues, closed networks, layered QN, fork-join, caches, and random environments.

Solver Guide

SolverBest For
MVAProduct-form networks with exponential service (fast, exact)
NCClosed networks needing exact normalizing-constant analysis
CTMCSmall state-space models; supports non-product-form features
MAMPhase-type / MAP service distributions (matrix analytic)
SSAStochastic simulation; works for any supported model
FLDFluid / ODE approximation for transient and large models

Output Formats

All analysis tools accept a format parameter:

  • text (default) — Human-readable table with model summary header
