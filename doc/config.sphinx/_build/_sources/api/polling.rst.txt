Polling Systems
===============

Analysis of gated, exhaustive, and k-limited polling.

The ``polling`` module implements algorithms for polling systems with various
polling strategies (gated, exhaustive, k-limited).

**Key function categories:**

- **Gated polling:** :func:`~line_solver.api.polling.polling_qsys_gated`
- **Exhaustive polling:** :func:`~line_solver.api.polling.polling_qsys_exhaustive`
- **Limited polling:** :func:`~line_solver.api.polling.polling_qsys_1limited`
