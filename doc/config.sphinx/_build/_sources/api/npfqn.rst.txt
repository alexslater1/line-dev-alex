Non-Product-Form Networks
=========================

Approximations for intractable queueing networks.

The ``npfqn`` module provides approximation methods for non-product-form queueing
networks that do not satisfy BCMP conditions.

**Key function categories:**

- **Traffic merging:** :func:`~line_solver.api.npfqn.npfqn_traffic_merge`, :func:`~line_solver.api.npfqn.npfqn_traffic_merge_cs`
- **Traffic splitting:** :func:`~line_solver.api.npfqn.npfqn_traffic_split_cs`
- **Service approximations:** :func:`~line_solver.api.npfqn.npfqn_nonexp_approx`
