\section*{Use of Generative AI}

I acknowledge the use of generative AI tools, such as Claude, in this project. 

GenAI is increasingly becoming an efficient tool in software engineering to support the implementation of features. Whilst it was used in my project, all ideas were my own and features were considered and constructed carefully, as my intentions for the project and domain knowledge I gathered over the project were ideas that could only I could motivate. However, I found it useful to get AI to regularly refactor and document my code to help maintain what eventually became a large codebase.

While writing my report, GenAI has been a valuable tool in formatting LaTeX, however once again it was not the right situation to use heavily in writing, as the project timeline and intentions, framing and domain knowledge are only things I could contribute.
